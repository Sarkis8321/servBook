# servBook
# Электронный учебник по курсу "Серверные языки программирования (язык PHP)"

Дипломная работа: Разработка электронного учебника с регистрацией учащихся и учителя.

## Описание проекта

Веб-приложение для изучения языка программирования PHP, включающее:
- 8 модулей обучения с теоретическим материалом
- Тесты после каждого модуля
- Итоговый экзамен по всему курсу
- Личный кабинет студента с отслеживанием прогресса
- Панель учителя для контроля успеваемости
- Возможность управления вопросами тестов

## Структура курса

### Модули:
1. **Введение в PHP** - Основы языка, синтаксис, переменные, типы данных
2. **Управляющие конструкции** - Условные операторы, циклы, switch
3. **Функции в PHP** - Создание функций, параметры, возвращаемые значения
4. **Массивы в PHP** - Индексированные и ассоциативные массивы
5. **Работа с формами и данными** - $_GET, $_POST, сессии, cookie
6. **Работа с базой данных** - PDO, подготовленные выражения, CRUD операции
7. **Объектно-ориентированное программирование** - Классы, объекты, наследование
8. **Безопасность в PHP** - Защита от XSS, SQL инъекций, CSRF

### Тестирование:
- После каждого модуля - тест из 4 вопросов
- Итоговый тест - 10 вопросов по всему курсу
- Типы вопросов: одиночный выбор, множественный выбор

## Технологии

- **Backend**: Node.js + Express.js
- **База данных**: SQLite (better-sqlite3)
- **Шаблонизатор**: EJS
- **Аутентификация**: express-session + bcryptjs
- **CSS**: Собственные стили

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Инициализация базы данных (создаётся автоматически при первом запуске)
npm run init-db

# Запуск сервера
npm start
```

Сервер запустится на http://localhost:3000

## Учётные данные

### Учитель по умолчанию:
- Логин: `teacher`
- Пароль: `teacher123`

### Регистрация новых пользователей:
Доступна через страницу /register
- Студенты регистрируются с ролью "student"
- Преподаватели могут регистрироваться с ролью "teacher"

## Функционал

### Для студентов:
- Просмотр учебных модулей
- Прохождение тестов после каждого модуля
- Сдача итогового экзамена
- Отслеживание своего прогресса
- Просмотр результатов тестов

### Для учителей:
- Панель управления со списком всех студентов
- Просмотр успеваемости каждого студента
- Статистика по пройденным модулям
- Добавление новых вопросов в тесты
- Удаление существующих вопросов
- Создание вопросов для итогового теста

## База данных

### Таблицы:
- `users` - Пользователи (студенты и учителя)
- `modules` - Учебные модули
- `questions` - Вопросы тестов
- `answers` - Варианты ответов
- `user_progress` - Прогресс пользователей
- `user_answers` - Ответы пользователей

## API Endpoints

### Публичные:
- `GET /` - Главная страница
- `GET /login` - Страница входа
- `POST /login` - Аутентификация
- `GET /register` - Страница регистрации
- `POST /register` - Регистрация нового пользователя

### Для авторизованных пользователей:
- `GET /dashboard` - Личный кабинет
- `GET /module/:id` - Просмотр модуля
- `GET /module/:id/test` - Тест по модулю
- `GET /final-test` - Итоговый тест
- `POST /submit-test` - Отправка ответов
- `GET /logout` - Выход

### Для учителей:
- `GET /teacher/dashboard` - Панель учителя
- `GET /teacher/student/:id` - Успеваемость студента
- `GET /teacher/questions` - Управление вопросами
- `POST /teacher/questions/add` - Добавить вопрос
- `POST /teacher/questions/delete/:id` - Удалить вопрос

## Особенности реализации

1. **Безопасность паролей**: Хеширование с помощью bcryptjs
2. **Сессионная аутентификация**: express-session для управления сессиями
3. **Защита от SQL-инъекций**: Использование prepared statements в SQLite
4. **Адаптивный дизайн**: CSS с поддержкой мобильных устройств
5. **Модульная архитектура**: Разделение логики и представления
